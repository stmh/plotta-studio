# SVG Fonts

This directory contains SVG font files for use with plotta-studio.

## Relief SingleLine

**File:** `ReliefSingleLine-Regular.svg`

A high-quality single-line font designed specifically for pen plotters, laser engraving, and CNC applications.

**Source:** https://github.com/isdat-type/Relief-SingleLine

**License:** SIL Open Font License 1.1 (see `OFL.txt`)

**Copyright:** 2022 The Relief SingleLine Project Authors

### Features
- Full Latin character set
- Designed for single-stroke rendering
- Professional typographic quality
- Open source and freely redistributable
